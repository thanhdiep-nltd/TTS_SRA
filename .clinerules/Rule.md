# RULES FOR MCP USAGE

1. Sequential Thinking:
   - MUST activate `sequential-thinking` BEFORE solving any complex bug, refactoring code, or designing architecture.
   - Do NOT skip step-by-step reasoning when handling multi-file changes.

2. Code Review Graph:
   - MUST call `code-review-graph` before modifying existing functions/modules to analyze blast radius and dependencies.

3. Knowledge Graph Memory:
   - ALWAYS query `memory` at the start of a new task to recall project conventions/decisions.
   - SAVE critical architectural decisions or custom user guidelines to memory immediately.

4. Browser Automation:
   - ONLY use `browser-automation` when verifying UI/E2E behavior, capturing visual feedback, or scraping live web data.
